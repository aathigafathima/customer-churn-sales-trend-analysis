# Customer Churn / Sales Trend Analysis

## Project Overview
This project analyzes e-commerce sales data using Python and Pandas.

## Features
- Date extraction and feature engineering
- Monthly and yearly sales analysis
- Pivot table analysis
- Customer sales analysis
- Category-wise profit analysis
- Actionable business recommendations

## Tools Used
- Python
- Pandas
- Google Colab
- GitHub

## Dataset
Superstore E-commerce Sales Dataset

## Key Analysis
The project identifies sales trends, high-value customers, and profitable product categories to support business decision-making.
